# 工程脚本说明

本目录保存数据准备、验证、发布审计和工程资料打包脚本。所有命令均在仓库根目录执行。

## 数据与验证

- `inspect_data.py`：检查输入数据结构与字段完整性。
- `prepare_data.py`：生成确定性工具使用的标准化输入。
- `run_d4_validation.py`：执行三类代表性场景验证。
- `run_d5_experiments.py`：执行 40 项冻结批量实验。
- `audit_d5.py`：核对 D5 结果、统计量和冻结文件哈希。
- `audit_d6.py`：核对发布文档、部署配置和工程完整性。

## 工程资料打包

```bash
python -m scripts.package_release
```

默认输出：

- `dist/智行合一-工程资料-20260925.zip`
- `dist/智行合一-工程资料-20260925.json`

打包器采用白名单收集源码、配置、测试和必要验证材料，排除 Git 历史、缓存、运行时数据库、原始团队资料及历史协作草稿。生成前会检查工作区状态、敏感凭据和本机绝对路径；压缩包内附逐文件 SHA-256 清单。
