## 检查程序与使用方法

```powershell
# 递归检索当前项目，缺失时输出missing_data、退出码2
.\.venv\Scripts\python.exe scripts/inspect_data.py

# 资料包位于项目外时，递归查找指定目录
.\.venv\Scripts\python.exe scripts/inspect_data.py --search-root 'D:\实际资料包路径'

# 也可以指定任意文件名；列映射按实际表头另行填写
.\.venv\Scripts\python.exe scripts/inspect_data.py 'D:\实际资料包路径\data.xlsx' 'D:\实际资料包路径\log4p-10-29(1).csv'
```

输出在已被Git忽略的`artifacts/d1-inspection.json`。源文件只读，输出不得覆盖输入。CSV严格解码，支持UTF-8/BOM、GB18030、带BOM的UTF-16；逗号、分号、制表符、竖线分隔符自动检测。XLSX标准OOXML使用缓存公式结果，没有缓存记为缺失，不计算公式。Excel序列时间需要mapping明确指定，不根据数值猜日期。

检查覆盖文件SHA256、大小、表名、行列、空行、短/长记录、无名/重复列、记录重复、数据类型、缺失、非有限值和负值。显式时间映射后检查时间范围、缺失/无效/重复/倒序、间隔中位数和大段中断；缺失或无效时间不跨越积分/间隔计算。默认中断阈值300秒仅是可调整的体检阈值，不是船舶运行约束。

字段名、传感器语义和单位不通过统计自动证明。报告不导出原始行、字符串样例和坐标值。文件指纹和时间范围仍是本地研发记录，不将生成报告直接公开提交。
