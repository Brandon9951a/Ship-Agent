## D2处理建议

1. 源文件只读，清洗另存；报告空行、掩码、去重与保留数，原因重叠不重复扣减。
2. 冻结同时间多快照的通道对齐/去重规则，再按有效正时间积分；零/负/缺失间隔不累计时长。
3. 确认CSV单位、capacity/SOC、battery_pressure含义、双组边界及负值符号；未知单位只统计原值，不标定。
4. 水深`[]`标为非数值，不填为实测0；风速/状态码待解释。Excel全为负的水流速度需方向依据，不与平流假设混用。
5. 查明Excel与CSV整理和重叠关系，按真实航次或隔离时间块划分，防止不同副本造成验证泄漏。
6. 原调研报告、A采用参数和计量边界仍待确认。不报告尚未产生的模型误差、节能率或实船安全结论。
