## 实际映射与复跑

`configs/data_mapping.d1.json`默认检查CSV ISO时间；只对Excel表头明确单位的速度/功率/电压/电流做相应数值检查。CSV未知单位及capacity候选用`role=other`统计原值存在，不执行换算或SOC越界判断。示范文件`configs/examples/data_mapping.example.json`不是本次真实映射。

```powershell
.\.venv\Scripts\python.exe scripts/inspect_data.py --mapping configs/data_mapping.d1.json
```

`elapsed_seconds`不接受时区，输出相对秒范围；`excel_serial`只有明确选择时才使用日期系统，不猜数值日期。重复列名用索引映射；未确认单位不能选需要换算的role。资料提供者确认后同步更新映射和字典，再复跑；不能只改文字而保留错误程序输入。
