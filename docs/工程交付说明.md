# 工程交付说明

## 包内内容

- 完整可运行源码和前端静态资源。
- Python 依赖、无密钥环境变量示例和 Render Blueprint。
- 船舶、航线、约束及演示策略配置。
- 自动测试、场景验证、批量实验和发布审计脚本。
- 必要的架构、接口、算法、字段和最新验收文档。
- D5 冻结实验结果与逐文件 SHA-256 清单。
- `PACKAGE_MANIFEST.json`，记录源提交和包内文件哈希。

## 不包含内容

- `.env`、API 密钥、令牌和证书私钥。
- `.git`、虚拟环境、缓存、日志和本地 checkpoint 数据库。
- 原始船舶调研文件、历史航行原始数据和未确认公开权限的材料。
- 作品方案、答辩 PPT、演示视频和佐证材料；这些材料单独提交。
- 本机用户名、绝对路径和内部协作分支流水账。

## 验证顺序

源码仓库包含 439 项测试。工程包排除依赖未分发原始证据的测试和依赖 Git 元数据的打包器自测，包内保留 424 项可独立运行测试。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m scripts.audit_d6
```

启动驾驶舱：

```powershell
.\.venv\Scripts\python.exe -m ui.web_server --host 127.0.0.1 --port 8765
```

浏览器访问 `http://127.0.0.1:8765`。未配置外部模型和语音凭据时，确定性计算与模板说明仍可运行。

## 完整性检查

1. 计算 ZIP 文件的 SHA-256，与外部清单比较。
2. 解压后读取 `PACKAGE_MANIFEST.json`。
3. 核对 `source_commit`、`file_count` 和逐文件哈希。
4. 按上述顺序安装并运行测试。

## 验证口径

D5 冻结批量实验 40 项全部通过，其中 32 项可行、8 项因 SOC 约束不可行。22.5220% 只表示同一演示模型和离散候选网格内的策略差异，不能解释为实船节能率。

## 使用限制

系统输出仅用于航行辅助决策原型演示。实船使用前必须完成数据协议、模型标定、航道限制、安全保护和运营审批核验。
