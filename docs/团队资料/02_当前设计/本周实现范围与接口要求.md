# 本周实现范围与开发接口要求

具体字段、单位、状态和工具交换结构，以 [五工具接口契约](../../接口/五工具接口契约.md) 和仓库 schemas 为第一依据。本文件描述总体范围；B/C 按已确定的接口实现，不另设接口审批。

本周目标是稳定文本原型和完整赛事交付。技术方案、图结构和反思机制描述完整目标设计，若涉及完整仿真、双电池FDP、语音、训练或船端离线部署，本周均按后续规划处理。

## 必须通过的三个场景

1. 正常航行任务：自然语言输入，输出真实航段、航速、到达时间、能耗、SOC和风险说明。
2. 到达时间不可行：工具判定并解释，生成工具试算支持的调整选项，用户选择后重新计算。
3. SOC不足：拒绝不安全方案，提供工具试算支持的补能或任务调整；未知充电能力须明确仿真假设。

缺参追问、错误停止、模型服务故障回退、子航线/返程距离校验也是必须验收内容。

## 数据与安全约定

- 配置保存设计值、调研值、来源、待确认项与本次采用值；不得把冲突值直接混用。
- 统一距离km、航速km/h、功率kW、能耗kWh、时间h；原始分钟和knots显式转换。
- SOC内部已定为0–1，展示为百分比；不要混用。
- 调研中的25%报警、20%停机需结合确认事实形成配置；报警不等于允许主动突破停机下限。
- 电池总容量不因两组输出而重复累计。未知拓扑不输出虚构双电池功率分配。
- 用户任务输入用于本次请求，填充值带来源；硬安全边界来自经A确认的事实配置，不能被用户随意放宽。重要安全字段未知则追问或明确拒绝。
- 网格/离散搜索只陈述其搜索空间内结果，不声称未证明的全局最优。
- 方案对比使用相同任务、航线、载荷、环境和硬约束。
- 模型负责语义与解释，数值调整由真实工具试算，用户选择可允许的方向，最多两轮重算。

## 模型与能耗建模

本周云端大模型API可配置base_url、model和凭据环境变量；D1真实试通后记录实际model标识。配置事实与提示上下文先支持领域任务，不安排大模型微调或本地推理部署。

B依旧需要拟合、验证物理能耗模型，这是数值建模。对外只报告当前实验结果，不能直接把设计参考中的R²或节能数字当作本次测试成果。
