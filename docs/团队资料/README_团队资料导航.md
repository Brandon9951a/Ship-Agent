本目录包含当前开发计划、设计参考、官方比赛规范和必要的说明资料。源码位于仓库根目录。完整团队资料包由A另行共享，本目录不包含原始航行数据、大型调研文档、展示PPT或压缩包。

## 目录用途

| 目录 | 内容 | 使用人 |
|---|---|---|
| 00_必读 | 分工、每日验收、交付要求 | 全员 |
| 01_赛事规则与模板 | 官方规则PDF/TXT及方案模板DOC | A、C；B读验证要求 |
