# 航行数据使用说明

本目录包含三份业务原始数据副本，B负责清洗和建模，C负责辅助字段与来源整理。应保留原始文件，清洗结果另存到开发仓库约定的输出目录。

| 文件 | 初步数据规模 | 使用方向 |
|---|---|---|
| data.xlsx | 12257行、60列 | 航行/设备字段核对、能耗样本 |
| log4p-10-29(1).csv | 38146行、74列 | 能耗样本、航行工况验证 |
| log4p-10-31(1).csv | 85551行、74列 | 能耗样本、离线验证 |

以上是数据记录行数，不含表头。两个CSV共123697行。字段定义和统计在实际清洗后复核。

## B/C应交付

- 数据字典：字段、单位、传感器含义、时间基准、缺失率与用途。
- 清洗统计：保留/剔除/标注多少记录及原因。
- 可复现的清洗脚本和合法可分享的小样本。
- 按航次或时间隔离的训练/验证划分，避免同一次连续航行的相邻点泄漏。
- 能耗预测验证：预测与实测功率/能耗、误差、样本量和适用工况。
- 数据来源、允许共享范围和脱敏说明。

## 已知核查点

- Excel列数与部分方案描述不一致；实际发现60列，需要解释异常的Unnamed列。
- 航速可能以knots记录，不能直接当km/h。
- 功率存在负值，先核查回馈/传感器定义，不能一概按异常删除。
- 区分停船、过闸、低速与稳定航行工况。
- 两组电池SOC、电压、电流与容量的关系需结合船舶资料确认。
- GPS、时间戳和设备信息供团队内部研发使用；公开参赛工程中的数据分享按来源权限整理。
