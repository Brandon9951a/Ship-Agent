# B的D2代码审查

审查日期：2026-09-19。审查对象：`origin/codex/b-d2-lwj@81eb6b8`。审查在独立临时目录执行，原分支315项测试全部通过。本记录区分“代码行为正确”与“实船模型已验证”；后者仍未完成。

## 可以保留的内容

- 只读数据准备不改原文件，输出写入忽略目录并拒绝覆盖已有结果。
- CSV未知单位不擅自换算；XLSX只对表头明确单位的通道转换。
- 缺失、重复、倒序、大时间间隔、负功率和停船分别留痕，不先删除或填零。
- 梯形积分在跨零区间分开正负面积；训练和验证分组要求完整、互斥。
- Tenergy要求明确模型编号、系数、辅助功率、能耗口径及演示/正式用途。

## 合并前必须修改

1. **正式结果来源校验**：原实现允许`usage=approved`时使用`confirmed=false`的航段来源。已改为返回`need_clarification`。
2. **假设不能丢失**：原实现没有把`Segment.assumptions`带入`EnergyResult`。已改为逐条保留。
3. **能耗分项可审计**：原输出只保留总能耗，推进与辅助能耗分项在接口处丢失。已给`EnergyResult`增加可选分项并校验总量关系。
4. **功率约束输入**：三次方模型能够计算候选航速下的模型峰值，原实现固定输出`peak_power_kw=null`，导致后续功率约束无法判断。已输出模型计算峰值；不得称为传感器实测峰值。
5. **采用参数过期**：B分支仍把容量、SOC、辅助功率和拓扑标为`pending_A`。已按A于2026-09-19的演示决策更新，并保留实船未知项。

## 仍未完成

- 历史数据的CSV单位、SOC候选字段和功率计量侧仍未全部确认。
- 三次方系数尚未通过独立航次完成真实标定与验证。
