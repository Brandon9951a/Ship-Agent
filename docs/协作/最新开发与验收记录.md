## 已完成

1. 不可行任务进入 `prepare_adjustment → await_choice`，通过 `interrupt()` 暂停。
2. 船员只能选择服务端生成并验证的 `option_id`，不能从浏览器提交自定义工程参数。
3. 采用调整方案后完整重跑 `Tdata → Tseg → Tenergy → Tspeed → Tmanagement`。
4. 最多允许两轮调整；放弃任务不增加重算轮次。
5. 本地使用 SQLite，Render 使用 PostgreSQL；服务重启后可按 `thread_id` 恢复。
6. `/api/resume` 和 `/api/runs/{thread_id}` 已接入并覆盖错误码与重复恢复测试。
7. 页面支持待确认任务恢复、轮次轨迹、按钮防重复提交和内联状态反馈。
8. 科大讯飞凭据只从服务端环境读取，页面只接收可用状态。
9. Render 线上服务已验证：`checkpoint_backend=postgres`、`checkpoint_ready=true`、`speech_mode=iflytek_iat`。

## 发布边界

- 当前结果属于软件演示和方法验证，不是实船安全或运营结论。
- 22.5220% 是同一演示模型与离散候选网格内的策略差异，不是实船节能率。
- 真实航段限速、充电功率、传感器协议、BMS 保护值和模型标定仍需现场确认。
- 工程包不包含 API 密钥、原始航行数据、原始调研附件、成员个人路径或 Git 历史。
