# D3 A演示参数决策与集成记录

日期：2026-09-20。负责人：A。用途：D3正常任务的软件仿真联调。

## 决策

- 采用独立的`synthetic_demo`配置，不修改或冒充真实航道限速、实船批准参数及实船验证结论。
- 依据调研报告“三（2）航速与功率”中的“经济航速约6 knot、日常功率约90 kW”，换算速度为11.112 km/h，并按`P=a×v³`得到单点锚定系数`a=0.06559425611908812 kW/(km/h)³`。
- 能耗模型口径为推进功率`propulsion`。演示辅助负载30 kW由Tmanagement按全程时长加入一次，禁止在Tenergy和能量管理中重复统计。
- 将11.112 km/h作为本次软件演示运行上限，候选速度为7.408、9.26、11.112 km/h，分别对应4、5、6 knot。该上限不是航道法定限速，也不是实船运营批准速度。
- 历史Excel的表头明确航速单位为knots、主电机功率单位为kW；正功率且正航速的可读样本覆盖至约6.17 knot。由于功率测量侧、数据整理来源和稳定工况标签仍未确认，历史数据本轮只用于覆盖范围检查，不用于声称真实模型标定或误差验证。
- 演示有效总容量使用D2已批准的软件初值1411.065 kWh，即1567.85 kWh标称总容量乘90%初始SOH一次；两组容量不得再与总容量相加。

## 输出边界

端到端成功只表示输入任务在上述软件演示约束和单点锚定模型下可行。所有结果必须显示`synthetic_demo`、单位、来源和风险说明。真实航段限速、能耗标定、充电能力、BMS硬件保护和实船控制仍是外部缺口。
