## 4. 调用接口

```python
from core.llm_layer import LLMClient, LLMConfig, LLMConfigError

try:
    config = LLMConfig.from_env()
    result = LLMClient(config).complete_text(
        "这是文本理解测试，不包含航行数据。",
        max_tokens=128,
    )
except LLMConfigError:
    # 配置不合法：交编排层处理，日志不要打印配置原文。
    result = None

if result is not None and result.status == "ok":
    text = result.text
    # 解析场景需再校验 JSON 和 VoyageRequest。
    # 报告场景需以工具字段生成数字，不能直接使用模型编造的数值。
elif result is None or result.requires_fallback:
    # 这里是交编排层进入既定回退/追问流程的信号。
    # 规则解析和模板报告尚待后续实现，不在此假装已自动执行。
    pass
```

LLMCallResult：

| 字段/属性 | 意义 |
|---|---|
| status | ok / unavailable / failed，仅为模型调用状态 |
| text | 成功时的文字；失败时为空 |
| provider | 配置的平台标识 |
| requested_model | 请求模型 |
| response_model | 服务实际返回的模型标识，可为空 |
| error_code | 故障类别，可为空 |
| latency_ms | 本次耗时，可为空 |
| requires_fallback | 是否需要编排层处理故障/回退 |
| to_log_dict() | 脱敏日志字典，不含正文、提示词或密钥 |

模型调用的 status 不直接等同五工具的 ToolResponse.status，也不能把模型调用 ok 当成航行方案可行。编排必须按统一五工具接口契约执行数值与安全验收。

## 5. 故障分类与本周回退路线

| 状况 | 当前适配器行为 | 后续编排行为 |
|---|---|---|
| 调用关闭 | unavailable / disabled，不发网络请求 | 规则解析或结构化输入路线 |
| 必填配置缺失/非法 | LLMConfigError；CLI 返回 config_error | 提示负责人修复；允许已有数值工具独立运行 |
| 超时/网络故障 | failed / timeout 或 network_error | 回退或说明当前不可处理，保留故障状态 |
| HTTP 拒绝/限流/服务异常 | failed / http_状态码 | 负责人核对服务商控制台，不虚构成功 |
| HTTP 重定向 | failed / redirect_refused | 核对已批准接口地址 |
| 空或格式错误回复 | failed / empty_response 或 invalid_response | 拒绝把回复当解析结果 |
| 回复被截断/未完成 | failed / incomplete_response | 不使用残缺语义或 JSON |
| 其他异常 | failed / unexpected_error | 不记录原始异常中可能包含的秘密 |

本周既定回退路线：

1. 任务理解失败时，规则解析器只提取能确定的字段，交 schemas 校验；不理解或缺关键字段时追问。
2. 已有完整结构化输入时，数值工具可独立计算，工程数值不依赖模型生成。
3. 说明生成失败时，从通过验收的工具字段生成模板报告，并显示回退标识。
4. 工具本身失败、参数未知或任务不可行时，仍按契约追问/拒绝/报错，不能借回退生成成功方案。

上述是后续模块需要落实的约定。此次仅完成模型调用失败信号与处理边界，没有将规则解析或模板报告标成已实现。

## 6. 本地检查与真实连接测试

在仓库根目录执行，仅检查配置，不发请求：

```powershell
.\.venv\Scripts\python.exe -m core.llm_layer
```

A 在本地填写密钥并确认后，执行一次真实测试：

```powershell
.\.venv\Scripts\python.exe -m core.llm_layer --smoke-test
```

测试只发送 API 连通性短文本，要求回复 OK，不发送船舶数据、GPS、资料文件或业务请求。日志记录请求/实际模型标识、状态、故障代码与耗时，不打印密钥或回复正文。

CLI 退出码：0 表示检查正常/连接成功；1 表示连接未成功；2 表示配置不合法。仅检查配置成功不等于已经连接成功。
