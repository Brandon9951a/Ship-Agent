# 能耗基线与验证设计

对应D1/B3，依据最新A接口契约。首个数值基线采用电池侧速度三次方模型，D1确定计算口径与验证条件，D2拿到数据后拟合系数。尚无新实验误差、节能比例或模型准确度。

能耗预测由Python数值模型完成，与大语言模型的语义理解/文字解释分开；拟合物理模型系数不是大模型微调。本次仅冻结方法，未训练或微调大模型。

## 计算口径

对确认处于稳定航行且有同一计量边界记录的样本，拟合非负系数`P_prop_battery(v) = a × v³`，速度为km/h、功率为kW，a的单位为kW/(km/h)³。不把设计功率/最大航速强行当作实测标定点。若真实数据证明需要截距/载况分层，记录其物理意义后再扩展；已有文档R²=0.8644不是本次拟合成果。

若原始记录仅有轴侧功率，需确认传动效率和电池转换边界；未知效率时拒绝把轴功率当电池消耗。如果只有总电功率，须按总能耗建模并确认是否覆盖辅助负载，不先拟合总量再加一遍生活负载。

每段航行时间`h_move = distance_km / speed_kmh`，总时长`h_total = h_move + waiting_h`。缺失等待、限速、容量、安全下限、辅助功率和来源时返回缺参，不能填零。航行/等待期间的推进与辅助负载分别根据来源计算，停船推进功率是否为零也需明确建模假设。

Tenergy输出遵循`EnergyResult`：

- `duration_h`包含等待。
- `energy_scope`明确为propulsion或total。
- 以总能量/总时长计算同口径平均`power_kw`，满足`energy_kwh = power_kw × duration_h`。
- `peak_power_kw`需实测/模型峰值依据，不能自动复制平均值。
- `model_id`关联系数、训练数据版本、工况范围、转换方式和假设。

对于历史瞬时数据，时间间隔换算为小时，梯形积分`ΔE = (P_i + P_(i+1))/2 × Δt_seconds/3600`，每个区间只计一次。重复、倒序、缺失时间和大段中断拆开处理，不把中断长区间强行积分。分别记录正向消耗与回馈贡献；负值意义、通道和累计电量边界未确认时，不报告净能耗准确度。

## SOC与功率安全

采用有效容量C，预算`C × max(SOC_initial - SOC_min, 0)`，SOC全部0–1。propulsion口径总需求加一次已核实辅助能量；total口径直接使用总能耗。按航段结束SOC输出`SocPoint`，损耗算入电池侧能量，不重复扣容量或辅助负载。

规划下限由A另行确认，停机候选0.20不自动成为规划下限。两组容量和独立输出拓扑未核实前只记录问题，不输出虚构的双电池分配。充电地点、可用性、功率和时间未知时只能返回待确认补能需求，不能声明补能后可行。

## 数据划分与公平对照

先按航次或时间块划分训练/验证集，再做拟合和任何统计预处理；保持同一连续航行的邻近样本在同一分组，避免随机拆分泄漏。保留独立验证文件/时间段，记录载况、速度范围、环境和可用记录数。无法确定航次时采用时间分隔并说明间隔和限制。

固定航速与优化方案使用相同起终点、距离、等待、载荷、环境、初始SOC、功率边界、时间约束和规划下限。固定航速方案不可行时，单独报告不可行，不能把违反时间约束的省电结果当作公平改善基线。网格搜索只能称离散候选范围内最优，并记录候选范围、步长、组合数和停止条件。

## 指标与证据

预测功率MAE/RMSE、能量绝对/相对误差、实际验证样本数、约束通过率、正常/时间不可行/SOC不足状态、耗时及环境均待实验后填写。误差分母接近零时不使用不稳定百分比指标；按工况分层报告。节能比例只有两方案在相同硬约束下均可行且有冻结结果时才计算。

每次结果保存输入任务、采用配置、来源和假设、代码版本、算法系数、划分规则、原始JSON/CSV及运行条件。约束time/speed/power/soc应可追溯至计算字段。接口测试证明的是代码约束行为，不证明实船效果。

## D2优先实现和阻塞

先落实字段单位/计量边界，完成只读清洗产物和统计，标定三次方系数，再实现Tenergy并用A的ToolResponse校验。Tspeed与Tmanagement进入D3，但D2应提供可联调的候选结果。

## 按实际数据补充的D2输入与处理顺序

Excel已有表头明确单位的`speed_over_ground(knots)`和`motor_power(kW)`，但功率计量侧未知；只有经批准转换边界后才能拟合电池侧模型。若暂只拟合电机功率，模型必须标为motor-side，不能宣称已预测电池总能耗。没有效率依据时不输出转换后的电池能量。

Excel时间为相对秒，不能生成日期/ETA；CSV2025-10-29与10-31无时区、分别有23,875与68,375个重复时间额外出现数。先确认多快照采集机制，按同步通道制定分组/对齐规则，保留同时间不同值的冲突，不直接“保留第一行”抹掉设备信息。只对有效正间隔积分，不按每行5秒累计。CSV航速缺失38.09%/33.71%，需有效输入掩码和分层统计，不能全部填零当停船。

capacity只是SOC候选，不能自动用于SOC准确度验证；battery_pressure未解释，不能直接当电压乘电流。功率、逆变器、电池、侧推和辅助通道建立边界表，只选一个确定计量口径，不把总功率与下游功率叠加。负值符号未确认时只保留/分层，不先报告净回馈。

查明Excel整理来源与CSV重叠，不能把相同航行副本放入训练和验证两侧。初步可用两个CSV日期作为来源分组候选，但不等于已识别独立航次；训练/验证采用何种时间隔离、速度/载况覆盖必须在D2说明。稳定航行筛选阈值和模型系数待D2冻结并留证据，本次不预填拟合结果。
