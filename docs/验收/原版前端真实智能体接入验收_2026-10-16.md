## 测试和验收方式

在独立审查分支执行：

```powershell
python -m pytest -q
node --check ui/frontend/app.js
node --check ui/frontend/research-bridge.js
```

本地网页：`http://127.0.0.1:8766/`。使用原有账号登录后，点击示例航次或输入短航段任务，再点击“计算仿真方案”。模型记录只展示模型给出的公开依据和实际响应，不展示未提供的内部思维链。

## 仍适用的研究边界

船态、电池、速度和等待规则为具名仿真假设；资料距离保留来源。LSTM 只做短轨迹研究验收；默认完整规划使用解析功率后端。此网页结果不代表实船批准或连续问题全局最优证明。主分支保持不变，经项目负责人验收后再决定并入。
