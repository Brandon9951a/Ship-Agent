出现 waiting_human 后，补充目的地恢复原线程：

~~~powershell
& $py -m research.scripts.run_agent --env-file $envFile --resume '<task_id>' --response-id reply-1 --text '目的地是漯河港'
~~~

CLI 的 --storage 必须与原任务一致。网页由 SHIP_RESEARCH_STORAGE 指定目录，默认 var/research-agent。
一个存储目录只运行一个服务进程，进程内两个后台线程。重启可读取结果及恢复等待；运行中的计算若进程退出会明确记为 process_interrupted，不声称自动接续。

## 专业工具与情景

集中配置：configs/research_agent.json，保存电池独立初态、环境假设、效率、辅助负载、DE/FDP 与预算。

| 工具 | 实现 |
|---|---|
| Tdata | 读取情景，允许用户明确指定当前速度和双电池初始 SOC，冻结快照及逐字段来源 |
| Tseg | 同版快照与连续航线；登记正向、返程、子航线；合成情景使用明确仿真地名 |
| Tenergy | 独立动作执行真实 LSTM 短轨迹；解析后端作为 Tspeed 的具名子调用执行 |
| Tspeed | 真实 DE，共同网格评价，保存选定需求；只有核验过的 FDP 瞬时功率上限可用于重搜 |
| Tmanagement | 同一选定需求交给双电池三模式 FDP，保存逐时功率、SOC、模式与诊断 |

默认子航线漯河船闸到漯河港，约 0.689 km。网格 5 秒，DE 种群 8、3 代、种子 211，FDP SOC 网格 0.05。
多航段情景含两个 0.25 km 仿真段，每段末等待 30 秒，距离、时间轴和等待负载均进入计算。
LSTM 使用有来源说明的合成历史夹具与真实权重；“真实”指实际执行模型，不代表新增实测历史或船态。
成功规划经时间、距离、能量、功率及双电池 SOC 复核后返回 research_feasible。预测返回 prediction_completed，不改变 planner_approved=false。

## 辅助工具

| 动作 | 输入与证据 |
|---|---|
| search_project_docs | 显式文档清单，BM25＋中文分词，最多五段、每段八百字，附文件、章节、哈希与状态 |
| query_task_results | 任务 ID、list/read/compare、工件引用；检查用户归属和哈希，时序读取支持 offset/limit |
| calculate | 固定算术、单位换算、日期时区时间差；Pint 与 datetime，不执行模型生成代码 |

单位换算必须用 convert，系数由库提供。直接数字必须能在用户输入中找到；已有结果使用工件字段引用。
比较保留两侧引用，代码计算历时、母线能耗及末端 SOC 差值，输入不同不称为优化提升。
结果追问示例：请读取任务 <task_id> 的 Tmanagement 工件 <artifact_ref>，查询 result.payload.rows 的前十行。

## 主图、存储与接口

入口 research/agent/runtime.py：parse → reconcile → decide → guard → execute → reconcile。
await_human 使用 LangGraph interrupt；finish 负责模型正文与校验。
上限：16 次决策、6 次辅助调用、3 次无效动作、2 次 DE—FDP 循环。模型网络可重试故障重试一次，答复修正一次，仍失败时明确展示工具摘要。
数值由核实字段占位符渲染，模型不能重新抄写数值或改单位；定性文字仍需人工验收，不等于形式化语义证明。

SQLite 保存任务、事件及检查点，JSON 保存模型响应与数值工件。事件记录真实模型、请求 ID、公开依据、参数、耗时、父子关系及输出引用。
网页每秒按 seq 补齐事件，刷新恢复当前任务。恢复校验任务、版本、pending ID 与 response ID，重复回答不重复执行。

| API | 说明 |
|---|---|
| POST /api/run | workflow_mode=research_agent、task_text、scenario_id、task_type；后台执行，返回标识 |
| GET /api/runs/{id} | 状态、缺项、正文和结果引用 |
| POST /api/resume | 同模式、thread_id、pending_id、revision、response_id、reply_text |
| GET /api/runs/{id}/events?after_seq=0 | 每页最多 200 条已保存事件 |
| GET /api/runs/{id}/artifacts/{ref} | 归属及 SHA256 校验后读取工件 |
| GET /api/research/config | 情景和非秘密模型配置状态 |

沿用登录与 CSRF；研究存储另绑定用户，不能猜测其他用户任务 ID 或工件引用越权读取。

第二轮 FDP 场景还实际验证了 Tdata → Tseg → Tspeed → FDP 拒绝 → Tspeed 重搜 → search_unresolved，证据目录 var/agent-acceptance-v2，任务 97e3e6e6-a8a7-439f-87ac-0d6c93d2f7fd。最终一轮模型选择解释失败，符合“重搜或解释失败”的验收口径。
早期未通过的尝试保留在前两轮目录；最后一轮换算暴露手填系数问题，修正后单独重跑，最终记录明确保留被替代尝试的 ID。

| 场景 | 预期 |
|---|---|
| 子航线、多航段等待 | 实际 DE/FDP 与独立复核，research_feasible |
| 缺目的地、重启等待、重复恢复 | 只追问缺项，同线程继续，同一回答只执行一次 |
| FDP 拒绝 | 回送诊断，最多两轮搜索；解释失败或 search_unresolved，不发布成功 |
| 缺转换依据 | needs_input，指出 conversion_missing |
| LSTM 短轨迹、超窗口 | prediction_completed、model_out_of_domain，不暗换后端 |
| 检索、比较、换算 | 实际辅助调用，来源、差值、单位可核对 |
| 篡改、版本错配、越权 | 拒绝工件，Web 返回冲突或不可见 |
| 跳过 FDP、修改硬约束 | guard 拒绝，工具未执行 |
| API 不可用、正文数字错误 | 明确失败或修正后拒绝，不冒充验收通过 |
| 页面刷新 | 原状态、正文及事件恢复 |

## 保留边界

本轮不做途中充电、航中持续监测、完整协商试算或长时 LSTM，不证明连续问题全局最优。
FDP 已有本地跨进程可读的哈希 JSON 与受权 HTTP 入口，尚不是分布式生产工件服务。
研究规划当前接收剩余可用秒数，完整日历出发/到达语义留待后续；日期时间换算可用辅助工具执行。
SQLite 使用单进程服务，多实例协调与运行中计算的自动接续不在本轮范围。用户验收通过后再处理合入 main。
