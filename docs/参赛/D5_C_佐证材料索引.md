## 建议的佐证 PDF 编排

1. 目录和材料状态表。
2. 航线资料来源和逐段核对页。
3. 软件界面和三类场景截图。
4. D5 冻结实验摘要及原始文件索引。
5. 真实专利、论文、合作或调研材料。
6. 证据边界、数据权限和匿名检查说明。

最终合并前由 A 确认可公开范围，C 只合并真实持有且允许披露的文件。
