# 作品提交材料总目录

本目录是本项目从 2026-10-15 起统一维护的参赛材料工作区。当前作品名称沿用“智行合一”；四字新名称尚未确认，不擅自替换报名名称或历史文件名。

| 路径 | 用途 |
| --- | --- |
| `00_官方依据/` | 用户提供的六张官方规则截图。截图 04 是其他赛题的大文件命名示例，只借用通用命名规则。 |
| `作品上传要求.docx` | 按截图汇总的上传、格式、命名、内容和评分要求。 |
| `01_方案文字/` | 新写的方案文字和后续审阅稿。首份独立文字稿目前只在本地供负责人审阅，尚未公开上传；原始 V5 只读保留在 `docs/团队资料/02_当前设计/`。 |
| `02_待提交成品/` | 后续放最终说明书 PDF、答辩 PPT PDF、演示视频 MP4、佐证 PDF 等经核验的成品。 |
| `03_佐证与工程链接/` | 后续放佐证索引、代码包清单、百度网盘链接与提取码、提交回执；密钥和受限原始数据不得入库。 |
| `待完成与完善清单.md` | 按当前项目状态维护的详细工作清单，目前仅在本地供团队审阅，尚未公开上传。 |

源头资料和工程代码保留在原位置，必要时在本目录建立索引，避免复制多个失去版本关联的副本。最终向报名系统提交前，依照真实团队编号生成规定名称，并核验材料截止时间、系统字段、匿名要求和网盘可访问性。本仓库提交不等于赛事系统上传成功。
