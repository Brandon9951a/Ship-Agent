## 佐证整理规则

- 材料按“已持有 / 待索取 / 无法提供”分类。
- 文件名、日期、版本和来源必须写入内部索引。
- 证据只支持其实际覆盖的结论；不能用设计文档证明实测效果。
- 受理不能写成授权，离线验证不能写成在线应用。
- 个人信息、学校标识和未获许可的合作信息在提交前由 A/C 复核。
