# D5 C 演示视频脚本

## 视频约束

- 目标时长：3-5 分钟。
- 输出格式：MP4，大小不超过赛事要求。
- 演示对象：冻结版本的软件仿真界面。
- 当前状态：脚本已完成，视频尚未录制。

## 录制前准备

1. 在干净环境启动 `python -m ui.web_server`。
2. 打开 `http://127.0.0.1:8765`，确认页面显示“本地软件仿真”。
3. 确认截图和录屏中没有桌面路径、账号、密钥或身份信息。
4. 准备三条输入：正常任务、时间不可行、SOC 不足。
5. 使用与冻结版本一致的代码提交和配置，不临时修改参数。

## 分镜脚本

| 时间 | 画面 | 解说要点 | 证据边界 |
|---|---|---|---|
| 0:00-0:20 | 任务输入页 | 介绍豫交投001、平顶山港至周口方向和软件决策目标 | 不称实时船舶控制 |
| 0:20-0:55 | 正常任务运行 | 输入起终点、SOC、载况和时间约束，展示五工具过程 | 结果为 synthetic_demo |
| 0:55-1:35 | 正常结果页 | 展示航段、航速、ETA、能耗、末端 SOC、来源和约束 | 数值来自工具，不是实船效果 |
| 1:35-2:15 | 时间不可行 | 缩短最长耗时，展示 `infeasible/time`、原因和用户调整选项 | 系统不自动放宽安全下限 |
| 2:15-2:55 | SOC 不足 | 降低初始 SOC，展示 `infeasible/soc`、补能信息要求和安全拒绝 | 未知充电能力不作承诺 |
| 2:55-3:35 | 实验结果页 | 展示 40 项实验、30 项可比案例和限制说明 | 16.6703% 仅为当前离散模型内差异 |
| 3:35-4:00 | 追踪与限制 | 展示来源、工具轨迹、仿真标签和未解决资料 | 不宣称在线部署或实船验证 |

## 旁白中的固定表述

“本演示使用冻结的软件仿真配置。工程数值由结构化工具计算，模型结果标记为 synthetic_demo，不能替代实船安全验证、运营批准或真实节能率测量。”

## 录制验收

- [ ] 三个场景均可播放到明确结果或明确不可行状态。
- [ ] 正常场景显示来源、单位、ETA、能耗和 SOC。
- [ ] 不可行场景显示原因和用户调整选项。
- [ ] 视频中没有虚构访谈、实船控制、在线部署或未知充电能力。
- [ ] MP4 播放完整，时长和文件大小符合提交要求。
